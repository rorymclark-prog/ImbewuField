# Explicit NWS reference for a saved point

The existing Washington demonstration cannot describe another saved point. A saved site with a current grower-confirmed US description now has a separate explicit request control. It discloses that the coordinates, rounded from the canonical five-decimal site key to four decimals, enter the upstream NWS request URL. No full site key, alias identity, account identity or private label enters the action or its receipt. This does not authenticate ownership or US jurisdiction, and it does not change crop advice, planning dates or country readiness.

Both paths share the existing two-step transport: one total deadline, streamed response bound, exact official destinations, redirect refusal, application User-Agent and no retry. The point mapping must match the exact requested coordinate pair. Invalid point inputs cannot fall back to Washington. Both result types reuse the unchanged legacy payload algorithm. The old demo keeps its original receipt and guaranteed string label; the point receipt is distinct.

The client binds the full canonical site, every saved alias and normalized context/base, plus the shared observed actor/sample epoch. It rereads current aliases before requesting and publishing. Observed intervening changes, changed props, retired handlers and unmount discard delivery and visible values. Retiring a Server Action does not prove cancellation of already-running upstream work. No weather ledger, preference write or saved geometry mutation is added.

Official inputs are the [NWS API documentation](https://www.weather.gov/documentation/services-web-api), [disclaimer](https://www.weather.gov/disclaimer) and [OpenAPI schema](https://api.weather.gov/openapi.json), fetched by the coordinator on 6 November 2026. The schema constrains numeric point increments; this app uses fixed four-decimal strings to match them. That spelling is an application rule, not an agronomic figure. Numeric rate limits and future API-key timing remain unstated. Source retrieval time remains separate from forecast generation, update and validity times.
