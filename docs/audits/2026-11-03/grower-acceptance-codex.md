## Result

A complete reviewed proposal can save all planned cycles through the existing canonical crop book. The original review, actual account/sample context, current source, unchanged loaded base and fresh raw whole-book admission must still agree immediately before the single write. Only an actual confirmed writer receipt supplies success. A failed storage write permits a freshly checked manual retry; an unconfirmed completed write cannot invite a duplicate save. Dismissed or stale reviews and incomplete proposals stay held. These remain planned estimates, without observed planting, harvest, stock or sale records.

Finance checks relevant raw evidence before selecting current beds. An orphan or unresolved own-cycle marker therefore withholds the forecast instead of producing an empty-plan message or an apparently complete legacy benchmark. Actual picked/sold records remain visible. No own-cycle financial forecast was added.

Guest sign-in recognises a genuinely empty destination scaffold without treating authored growing profiles, nursery settings, unknown metadata or malformed collections as empty. Protected destinations retain their records and the guest evidence. This fixes the current client's sign-in path; it does not fence an older cached client.
