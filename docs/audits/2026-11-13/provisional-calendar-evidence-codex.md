## Implementation

Each valid marked cycle reuses `buildProvisionalCycleEvidence` from its checked assessment snapshot. Only public lines enter the transient task field. If marked evidence cannot be read, the cycle remains held; it does not become an ordinary-looking task. Dates, event UIDs, completion IDs and saved source/geometry are unchanged.

The task subtitle identifies the provisional plan. The operations panel exposes a collapsed source/limit disclosure with explicit English language marking. A detached bulk download copies and freezes the public lines alongside its existing public event fields. Both individual and bulk writers use the same description path, retaining sources, original/review dates, declared country/region, assumptions and unknowns. Unrelated metadata remains ignored. An unreadable, sparse, empty, non-string or accessor-based recognised evidence payload holds the complete file rather than silently removing qualifications. No getter is used to read that evidence.

The existing actor/source/state/checker/sample/lifetime checks remain around asynchronous delivery. A pending evidence-bearing export cannot revive after a country/source round trip. Ordinary cycles retain their existing description path; private source revision, policy, profile, geometry, raw request and journal-link fields are not serialised.
