# Private garden project progress report

The Task Planner offers a Food Security garden draft for a checked mapped site. The grower chooses the UTC reporting period, separate recording cutoff, harvest sources and any matching field notes. Preview and standalone local download use the same selected evidence. The site draft has no persisted project ID or sharing grant.

Harvest reads use the existing owner-scoped private link and server-confirmed harvest record. The observed picking day and UTC date of the original harvest entry are separate. Legacy missing dates stay unknown. The garden read can display an explicit zero already present in a linked source without changing how harvest records or links are written. The existing indicator evaluator excludes duplicate references, unsupported time windows, incorrect dates and non-kg values from the kilogram weight. Other quantities stay in their original units. Field notes only appear for a verified current garden, cycle, bed and event in the protected journal. They remain in a separate timeline.

Preview and download repeat the current source checks. Changing the selected site or dates, switching accounts, or unmounting the planner withdraws the draft. The report uses no shared visibility permissions and changes no stored farm record. Evidence cannot establish food access or project impact. Sample output is marked as illustrative.

Verification requires both Mkuze and Wisconsin phone journeys, opening the actual download, independent Codex review and exact-head CI. Keep production integration separate. A code rollback removes this read-only view and preserves the original crop and journal records.
