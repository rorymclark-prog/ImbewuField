# Own-estimate units and measured capacity

This branch adds metric and imperial entry for the grower's own plant-density and harvest-weight estimates. Unknown fields stay blank; zero remains an entered value. Days, months, crop identities and measured geometry retain their existing meaning. The panel remains English while the separate international translation packets await review.

The unit selector stages both densities together. Unfinished text holds both unit changes. Display rounding does not replace saved values. Each actual edit retains its original decimal text and unit separately from the display, including significant digits beyond a JavaScript Number. An untouched legacy profile gains no invented original-unit history. Reopening a saved receipt validates its profile, scope, crop, field, conversion identity and exact canonical projection again.

For a saved design, checking its current measurements supplies the manual and automatic review with the existing measured-source projection. The shared Design Studio bridge has an opt-in path without its historical one-decimal area rounding; existing display consumers retain their previous default. Rectangle factors come only from actual saved canonical metre dimensions. Circle/ellipse and calibrated polygon areas retain their existing footprint authority and declared numeric geometry semantics. Neither path certifies survey accuracy or recovers lost original feet input.

Whole-plant capacity uses integer quotient/remainder before Number conversion. It fixes engineering boundary cases such as 0.58 m² ×100 becoming 57, while a genuinely sub-integer decimal result still floors down. A validated density origin can supply its original denominator; a canonical-only legacy Number cannot acquire guessed imperial provenance. Arithmetic and software work limits are separate from local suitability or recommended crop densities.

The calculation version participates in review fingerprints. Old float-based reviews and saved dated-cycle markers require fresh review; their presence must remain held rather than becoming catalogue advice. Current source geometry, area arithmetic basis and profile receipt changes invalidate prior reviews.

Profile editing binds the complete loaded row and edit generation. A same-scope replacement or deletion cannot be overwritten by an old form. Explicit reload clears confirmation; starting anew clears the deleted identity. Failed saves retain the current draft. Ordinary crop-book writers preserve existing origin metadata. The real profile edit/remove action obtains a one-attempt permit bound to the current admitted book, actor, window and exact candidate. A malformed marker or stale operation grants no fallback. Genuinely old client bundles cannot retroactively acquire these guards or reconstruct metadata they already lost.

Validation, actual browser results and release status belong in the coordinator handoff. This document alone does not establish a passing current tree, deployed feature, fluent translation, local crop approval or production readiness. This changes the estimates screen and capacity arithmetic; `PLAN_VERSION` remains unchanged.
