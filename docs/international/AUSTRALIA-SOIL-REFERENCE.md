# Australia soil-depth reference

Australia is a research-queue dossier. TERN’s Soil Depth Release 2, version 2.0, describes modelled national soil-profile depth in metres at a reported grid resolution of three arc seconds, approximately 90 metres. The source describes uncertainty and a national model. Individual fields and beds still require local observations. The country review links the record without adding a layer, a lookup service, an agricultural region or crop-plan support.

The portal lists dataset publication on 28 October 2022, dataset modification on 11 October 2026, and metadata modification on 2 November 2026. The country card displays the latter as the source page’s modification. The portal lists updates as unplanned for this release. It identifies the dataset as CC BY 4.0 and gives a citation to B. Malone and R. Searle, TERN, DOI `10.25919/djdn-5x77`. Credit the original source and nominated parties if reusing the data. The licence statement describes this dataset record.

The portal advertises GeoTIFF, WMS and WCS links. These links were left untested. A separate attempt to open the RO-Crate link redirected to a TERN sign-in page. No account was used and no JSON, raster or map-service payload was retrieved.
