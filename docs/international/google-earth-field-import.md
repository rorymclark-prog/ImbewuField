# Local KML field import

Design Studio → Planting now reads a local KML file into a temporary outline preview. Nothing is selected or saved automatically. The user chooses distinct candidates and confirms an append. Existing fields, beds, paths and crop records remain intact. Imported outlines become ordinary proposed growing-field polygons; the existing field editor then configures beds and paths or open ground, and the saved-design check exposes the resulting areas to the grower-led automatic planner.

The first version accepts simple KML 2.2 Polygon placemarks with one closed outer ring. Namespace identity uses the URI, including valid prefixes. Unsupported placemarks are counted; ambiguous or overlapping candidates require explicit selection. Existing field or placed-element overlap is held. Holes, invalid topology, projection clamp/date-line crossings and outlines outside the current canvas are held. Photos and blank layouts need a matching map reference before import. Names and ordering never establish field-versus-bed identity.

The native browser XML parser receives bounded text after restrictive preflight. Declarations, comments, CDATA and noninitial processing instructions are outside this subset; network links, attachments and foreign-namespace elements are held. Parsed DOM nodes are never inserted into the page. This is neither full KML/XSD support nor a general XML-safety certification. KMZ and Google Earth client interoperability were not tested. Map-reference locations do not certify surveyed boundaries or regional crop suitability.

Original account/sample epoch, raw saved canvas, current frame/calibration and crop-book proof are captured before asynchronous file reading. Confirmation cannot borrow a replacement context. The actual parent save repeats the guards, recognizes only its own completed result on replay, and records one write/history action. No sowing, availability, harvest or stock observations are created by importing ground.

AGY authored the parser module under a bounded source order; independent source review and tests required corrections to numeric grammar, duplicate vertices, declaration handling and nested-geometry extraction. The coordinator additionally reproduced a long invalid decimal exceeding a two-second child-process limit and removed ambiguous regex backtracking without changing accepted decimal forms. Restoring the original expression through an in-memory loader hits the regression's five-second bound. Native command execution was not used as test evidence.

Coordinator verification: ordered Node 24 typecheck, **377 affected tests across 21 files**, whitespace and release-note gate pass. These include constructed-DOM parser checks, geometry checks, component checks, real canonical-storage/parent-writer cases, older exporter and unit/context regressions, and update-description checks. Constructed DOM fixtures do not establish native XML behavior; the following browser work does.

Actual local UI checks used normal file choosers and controls: default and prefixed XML previewed; malformed XML, foreign namespaces and declarations were held; cancelling preserved four sample fields; overlapping candidates could not be added together; one confirmed sample append added one field and duplicate reimport was held. On an independent synthetic local design, two imported fields survived full reload: one retained ten explicitly configured beds and paths, the other retained open-ground configuration. The real planner check exposed exactly ten beds and one open plot, all availability unchecked, while the country-advice hold remained visible. Dimensions were synthetic engineering inputs, not recommendations.

At 390 px, the document remained 390 px wide and buttons were at least 44 px high. Actual screenshots exposed an inherited cream-on-white text defect; the panel now pairs its background and text color, and the corrected output was inspected. Sparse local artwork/imagery remained unavailable. Temporary preview and browser resources were released after QA. Current-head full/security CI and authenticated hosted review remain release gates; this local evidence is not a production deployment.
