# Colombia biodiversity reference discovery

The country review links to the SiB Colombia public portal under biodiversity. The portal describes dated occurrence records, checklists and catalogue sheets. It says its data portal synchronises with GBIF. An occurrence represents a reported presence at a place and time. Suitability for a garden, completeness of local records and planting permission require separate evidence.

## Publisher licence options

The publication policy lists CC0, CC BY and CC BY-NC for biological occurrence records. The options shown for species sheets are CC0, CC BY, CC BY-SA and CC BY-SA-NC. These are policy options by data type. The licence and attribution for a particular dataset or record still need verification. The app leaves the reference's dataset licence unknown.

## Developer documentation

SiB Colombia's developer page describes a biological-record REST API with GeoJSON output and 31 query parameters. This review covers its HTML documentation. Endpoint operation, authentication, rate limits, response licence, update cadence and dataset resolution remain unverified. No endpoint, dataset or occurrence records were fetched. The app includes a link to the portal only.
