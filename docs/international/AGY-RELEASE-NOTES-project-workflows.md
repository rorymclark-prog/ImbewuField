# Proposed release note: project workflow evidence review

Adds a grower-led reference workflow for food security, livelihoods, agroforestry, agroecology and commercial market gardening. The new review screen lets a reviewer try fictional evidence examples, inspect source requirements and see why missing observations, planned values, duplicate references, incompatible periods or currencies cannot produce a complete result.

Existing records, tasks, journal, invoices, programme and MEL books remain the authorities. This foundation adds no second ledger, farm-data access or publication permission. It is an English review draft with generic workflow support; local farming advice, other languages, live-source integration and funding eligibility require separate review.

This changes the picture by adding `/international/projects`. `PLAN_VERSION` remains unchanged. Deployment and visual/full-suite evidence belong to the coordinator’s release review.
