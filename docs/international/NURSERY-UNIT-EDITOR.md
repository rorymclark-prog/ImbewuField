# Nursery entry and display units

The nursery editor offers one explicit, remembered choice: centimetres / square
metres, or inches / square feet. Country, language and currency do not select it.
Tray width and length remain canonical centimetres; net bench surface remains
canonical square metres. Counts, percentages, recipes and field dates retain
their existing meanings. No agronomic sizes or loss rates are supplied.

The shared dimension draft authority keeps the exact authored canonical number
through untouched display changes and reopening. It parses actual edits in the
unit shown when entered. Unknown optional tray measurements remain blank; a blank
required surface cannot be saved, and explicit zero surface or owned stock stays
zero. An incomplete edited dimension holds a unit switch instead of relabelling
its raw text. Surface is net growing area, not a rectangular packing guarantee.

The existing private preference authority has a separate, closed nursery purpose.
It remembers only the unit choice in the current account namespace. Sample
choice stays in memory. Missing storage and quota failures are reported without
pretending the preference was remembered. Server output starts with metric choice
and withholds private forms until the actor/sample context is captured.

All nursery edits share their original actor, site and saved-settings value
binding. Actual producer preparation holds inputs; its first valid context can
adopt a pristine editor. A later producer context cannot bless earlier unbound
legacy entries without explicit reload. Same-value object clones keep drafts. A changed saved source holds dirty
entries until explicit reload; account or sample transitions withhold the old
private forms and require reopening the crop plan. Retained callbacks are checked
again inside functional state updates. A unit preference cannot authorise a
crop-plan save.

Only the parent's opaque save acknowledgment can clear a submitted form or claim
a checked device/sample save. A plain boolean, void, thrown callback or unconfirmed
outcome retains entries and requires explicit saved-settings reload before retry.
No automatic retry or claim that a failed callback left storage untouched is made.
A confirmed save keeps other unfinished forms and binds them to the actual
confirmed source, including legitimate new inputs belonging to another site. Recipe/source issues and held
inputs continue through the existing nursery settings authority.

Exports use the same original context. The optional file-delivery context guard
blocks initial delivery and a delayed native-share download fallback after that
context is withdrawn. A file already shared cannot be recalled; stale completion
messages are suppressed. Unapproved local catalogue planning never invokes its
nursery forecast producer or offers its forecast export.

Mounted and pure tests establish wiring and arithmetic. They do not establish
phone layout, browser accessibility, human translation approval, local farming
suitability or observed nursery stock.
