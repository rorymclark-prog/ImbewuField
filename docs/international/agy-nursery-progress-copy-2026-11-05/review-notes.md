# Review Notes: Nursery Progress Count UI Copy (AI Drafts)

These 189 candidates across seven locales are unreviewed AI wording drafts for the nursery progress plant-count observation UI components.

Key technical and regional terminology distinctions requiring fluent review:
1. Horticultural plant counts. Observations apply specifically to plant nursery counts (*comptage de plants en pépinière* / *recuento de plantas de semillero*), distinct from animal husbandry, egg hatching, or childcare.
2. Grower assessment vs certified readiness. Stages (emerged, alive, ready) represent the grower's explicit qualitative observation. "Ready" must retain its assessment qualifier, distinguishing it from an agronomic readiness certificate or available inventory entry.
3. Count coverage. Explicit separation between a whole-batch count and a checked subset. A subset represents only what was directly inspected and must never be extrapolated to whole-batch totals.
4. Point-in-time observations. Repeated count observations remain discrete point-in-time records and are not summed together as accumulated stock.
5. Invariable numbers. An entered ASCII 0 denotes zero plants; a blank field denotes missing data and prevents submission.
