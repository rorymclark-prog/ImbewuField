## Current-source binding

## Review and export boundaries

The page lets a reviewer select a language, search and compare English with a draft. Current-source problems stay visible; frozen English is explicitly distinguished when current text cannot be verified. Counts describe structural drafts, not reviewed coverage. React renders draft text as text, including potentially hostile markup. The review reader reads no account, site, journal or farmer records; the page retains the existing navigation chrome.

The CSV worksheet exports all26 rows in the selected language, independently of the on-screen search, with current/frozen English kept separate and an empty reviewer-note column. The existing `csvCell` authority handles spreadsheet formulas, quotes and multiline text; stored drafts remain unchanged. UTF-8 BOM preserves multilingual text. Every exported human-review cell says unreviewed; even an unexpected reviewed assessment is exported as needs-review. The existing download helper requests a download; it cannot confirm a file was persisted.

No reviewer identity is authenticated, no decisions are saved or imported, no translation is approved, and no language is activated by this page or worksheet. Human/fluent review and local farming review remain separate requirements. Lessons, quizzes, audio, offline support, farming estimates, country context, currency, units, geometry and production records do not change.
