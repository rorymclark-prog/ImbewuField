# Saved field-layout export

Design Studio → Planting → Field blocks can download a selected saved field or all saved fields as KML2.2. A beds layout exports the existing boundary, materialized rectangular beds and saved path centerlines. An open field exports its boundary without creating beds. Export never applies unfinished settings, regenerates children or changes saved geometry. Labels are opt-in; the default uses generic numbered names. Demonstration-mode files identify DEMO throughout.

The first slice requires a matching saved/effective satellite map reference. It holds active photo/blank layouts, mismatched calibration, ambiguous child geometry, unsupported date-line crossing, unsafe descriptors or excessive software workload. Retained inactive photo metadata does not by itself invalidate a satellite reference. Coordinates are approximate map references, not surveyed boundaries or verified property rights. Path centerlines do not establish surveyed path widths. No crop, yield, legal or agronomic claim follows from an exported file.

Delivery rechecks the exact saved raw source, rendered selection/options, mounted account and sample session before creating a file and before delayed native-share download fallback. A changed source or context requires a fresh explicit request. Successful native sharing cannot be retracted; late UI feedback is suppressed if its source has changed. No cloud upload is introduced.
