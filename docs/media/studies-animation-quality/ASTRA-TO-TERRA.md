## Settled visual direction

Use the warm, lifelike rural South African Food Forest/Guilds benchmark: believable earth and leaf textures, natural light, locally grounded tools and buildings, people doing understandable work, and a clearly legible foreground subject. Respect people as capable farmers; avoid idealised abundance as an outcome claim. Keep one location, plant, animal and tool set consistent within a lesson.

For Flow: eight seconds, 16:9, one continuous action, locked camera by default, one or a few clearly separated subjects. Start from an inspected existing reference frame wherever possible. A detailed still does not prove good movement. Avoid cuts, time-lapse, crowded herds, complex handoffs and several simultaneous instructions. Do not request lettering, figures, interfaces or narrated speech from the video model. Reuse wordless footage for the two language tracks.

For authored visuals: retain photographic/illustrated context, then add precise shapes, masks, restrained highlights and controlled arrows. Do not rebuild animals from circles or primitive blocks. Keep explanatory overlays separate from the image. Use the existing typography and palette. On a 390 CSS-pixel phone, a learner must see the actual teaching action without reading a dense legend. Provide still, transcript and reduced-motion equivalents. Never bake important text into a low-resolution movie.

Film illustrates observed action. Diagrams explain relationships. Neither is evidence of measured restoration, safe food, animal health, soil fertility or legal permission.

## Acceptance and publication: what “complete” means

Track two statuses separately: MEDIA COMPLETE and RELEASE READY. A generated clip is neither. Media completeness can be achieved in English while fluent isiZulu/local practitioner/learner review is still outstanding; report those limitations explicitly.

- Inspect source and complete motion, then first/last frames and contact sheets across the entire clip. Check animal feet, fingers, counts, tool contact, fences, plants, water direction and all implied outcomes. Still-frame sampling alone does not prove temporal quality.
- Reject decorative motion that fails to show the intended learning point. Ask what a learner could correctly explain after viewing. A lovely rain scene with no legible soil-impact comparison fails S01.
- Verify the entire lesson in sequence: intro/question, explanation, example, practical task, feedback and next action. Transcript/audio must describe the actual visible action. Preserve accessible reading and sound-off use.
- Download original; decode video and audio fully; make a muted web derivative when separate narration is authoritative; create a matching poster and accurate byte sizes. Reuse current encoding conventions, not an arbitrary new format. Preserve originals outside public bundles.
- Register only accepted media and update the existing cache/offline manifest together. New narration requires its `lib/course-audio.ts` entry in the same commit. If text and narration cannot be reconciled, hold release. Never mark a missing language track complete.
- Inspect desktop and 390px player, pause/replay, reduced motion and a complete offline download/reopen. Confirm the new clip replaces the old cached clip without deleting unrelated downloads.
- Run `npx tsc --noEmit`, `npm test`, `git diff --check` in that order. All passing assertions and both CI jobs are required, plus visual evidence. Never change tests just to bless current output. Leave PLAN_VERSION unchanged.
- Save working milestones about every ten minutes; commit explicit paths locally. Push one finished branch per coherent release batch, inspect both CI jobs, publish only within the existing authorisation, and verify the production SHA and actual lesson. Record branch/SHA/evidence in issue #35. No unnecessary deployment for a planning-only packet.
