# Small Livestock: Tshivenda and Xitsonga review frames

**Review only.** These are silent static slide decks, not learner releases. All target-language text is unreviewed machine draft. No fluent-language or local-farming approval is claimed. Xitsonga uses standard written form and is provisional for Shangani; do not infer Shangani comprehension.

Each deck has 20 frames. Three low-risk passages are drafted and paired to exact English source text:

| Language | Slide | Exact English source | Draft status |
| --- | ---: | --- | --- |
| Tshivenda | 17 | Ask what useful things it produces. | Unreviewed machine draft |
| Xitsonga | 2 | Small livestock can do work beyond producing meat, eggs, or honey. | Unreviewed machine draft |
| Xitsonga | 17 | Ask what useful things it produces. | Unreviewed machine draft |

All other passages, including animal care, bee and hive safety, disease, manure, pesticide exposure, registration, crop consumption, water and feed plans, and site-specific guidance, stay exact English. A frame with no draft shows one English source card labelled “translation pending.” On mixed frames, rust text is explicitly labelled as an English hold and the full exact English source appears below.

No narration is included. The source-paired records are in this directory. `render-review.py` reuses `scripts/make-lesson-slides.mjs` and writes the static review frames, contact sheets, phone-size samples and SHA-256 verification records here. Source frames and text come from the current English Small Livestock deck.
