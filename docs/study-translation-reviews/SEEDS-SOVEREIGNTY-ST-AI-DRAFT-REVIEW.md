# Seeds and Seed Sovereignty — Sesotho review draft

**Status:** source-paired data only. It is not connected to learner Study. There
is no Sesotho slide deck or narration. No fluent Sesotho, seed-saving, farmer,
or ACT cohort approval has been recorded.

The draft covers the canonical module, its three lessons and six quiz items in
`lib/course-modules.ts`. It uses an unreviewed Sesotho machine draft for only
five display strings: the module title and description, plus each lesson title.
Every lesson body, infographic description, key point, quiz question, option
and rationale remains exact English and is marked `hold`. The six correct-answer
indices, lesson order, crop names, numbers and source metadata are unchanged.

## Why the teaching stays in English

The lessons explain open-pollinated seed and F1 hybrid variation; selecting
parents; crop-dependent maturity, crossing, fermentation and cleaning; drying,
storage, viability checks and exchange. A changed condition can damage the
next planting season. The existing English and isiZulu media cannot serve as
evidence of Sesotho audio or slides.

A fluent Sesotho reviewer with seed-saving experience should check the five
label candidates against the exact English source, including whether the word
for seed sovereignty is familiar to the Free State group. A seed-saving
reviewer should check any future translation of instructions, conditions and
quiz answers before it is shown as teaching. Add a separate deck and narration
batch only when text and media can be checked together.

## Draft provenance and checks

Agy CLI supplied the five low-risk candidate labels as a machine draft. The
remaining paired fields were copied mechanically from the canonical source,
without machine translation. The focused test checks all source pairs,
English holds, lesson/quiz coverage and answer indices. Neither a passing
test nor Agy output is language or local farming approval.
