# Recording sheet — Water Harvesting (isiZulu)

24 clips, 934 words. One clip per slide, numbered to match the deck.

## What to produce

Read each slide-NN.txt aloud in an isiZulu (zu-ZA) voice and save the clip as its own mp3.
Name the files exactly as below — scripts/import-course-audio.mjs reads these names, and a
clip under the wrong number puts the voice against the wrong picture for the rest of the deck.

```
isizulu/Slide_01_isiZulu.mp3
isizulu/Slide_02_isiZulu.mp3
...
isizulu/Full_Narration_isiZulu.mp3   (all slides read end to end)
```

Then bring them back with:

```
node scripts/import-course-audio.mjs water-harvesting <folder>
```

That command checks the pacing of every clip against the word counts below and refuses a set
where a clip is missing, empty, truncated, or built from the wrong block.
