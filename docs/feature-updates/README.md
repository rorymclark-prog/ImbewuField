# Important feature walkthroughs

Rory requested the animated update-card pattern on 5 November 2026.

Use the existing release notes and guide. Set `preview: 'assistant-access'` only
on the tour stop whose change matches that demonstration. Routine fixes need no
preview. A new feature needs its own accurate demonstration before it is flagged.
Do not animate a made-up farming measurement or real account data.

The animation runs once, can pause/replay, and becomes a complete still image
under reduced motion. Closing the guide records that this device has seen that
feature. What’s new → Guide me through the changes can always replay it.

The added release-note descriptions in `lib/update-copy-locales` are unreviewed
machine drafts. The existing UI pairs them with their English source.
