ImbewuField courses — everything for ChatGPT (images + bilingual posters)

One folder per course. In each folder:
  00-START-HERE-character-sheet.txt   do this first, in a new chat for that course
  01-images.md                         text-free images for slides and cards (one prompt per image)
  02-posters.md                        finished infographic posters, isiZulu + English
  03-style-reference.md                that course's look: colours, fonts, characters

Rules for every image: sun in the NORTH (shadows fall south), people look like the learners,
no real banknotes, AI is never a robot. Images in 01 must have NO text; posters in 02 have only the
exact words given.

Save each file with the name shown above its prompt (e.g. F-P06-ART.jpg, F-P06.jpg) and send
them back (or drop them into public/course-media/<course>/ in the repo). The build then puts them
into the slide decks automatically.

Counts: Grow Food 99 images + 21 posters · Walking With Farmers 28 + 16 · Teach the Teachers 42 + 22
· Farmer Money 31 + 17 · AI Literacy 31 + 14.
isiZulu text is a DRAFT until read back by a first-language speaker.
