# Codex handoff — images, animations and posters for the five courses

Claude wrote the courses (content, scripts, poster specs, slide specs, media briefs). **Codex
makes the pictures, the clips and the print-ready posters.** This file is the whole brief.

## 1. Where the work list is

`courses/media-manifest.json` — generated by `python3 scripts/courses/build.py`. Every item has:

| Field | Meaning |
|---|---|
| `id` | e.g. `F-ANI-17`, `F-P06-ART`, `M-IMG-04`, `F-P06` |
| `kind` | `image` · `animation` · `photo` · `poster-art` · `poster` |
| `status` | `NEW` = make it · `REUSE` = already in the repo (`reuse_path`), don't touch |
| `target` | exactly where to write the file |
| `brief` | what to draw / animate (poster-art briefs come from `posters.md`) |
| `used_in` | slide / session / poster IDs — open those to see the teaching context |

Never edit the manifest by hand. If a brief is wrong, fix it in the course's `media.md` or
`posters.md` and re-run the build.

## 2. House rules (all art, no exceptions)

From `poster-standards.md` §Art rules and the app's `lib/course-image-briefs.ts`:

1. **Southern hemisphere:** sun in the **north**, shadows fall **south**. Image models get this
   wrong by default — check every sun and shadow.
2. **No text, numbers or letters inside artwork.** Words are typeset on top (translatable).
   Exception: `poster` layouts (§4), where the typeset text *is* the job.
3. **Generic plant shapes** unless the brief names a crop that must be recognisable (food cards,
   pest cards). **Never draw a recognisable invasive species** (NEMBA).
4. **People:** Black South African smallholders and facilitators, mixed ages and genders, work
   clothes, gumboots, headscarves, caps. Warm, dignified, active — hands busy, not posing.
5. **Style:** flat, warm, instructional illustration; thick dark outlines; not photoreal, not 3D.
   Palette: Forest `#1F4D2B`, Mid-green `#2E6B3A`, Leaf `#A8D88A`, Ochre `#C07A1E`,
   Water `#235E86` (water only), Paper `#F7F2E9`, Ink `#20190F`.
6. **Local materials:** corrugated iron, JoJo-style tanks, 20 ℓ drums, 2 ℓ bottles, droppers,
   kraal manure, grass mulch, plastic chairs, lapas.
7. **One idea per picture.** Plain background unless the brief asks for a scene.

## 3. Formats

| Kind | Size | Format | Weight |
|---|---|---|---|
| `image` (slide) | 1600 × 900 | JPG | ≤ 250 KB |
| `image` (card) | 1080 × 1528 portrait | JPG | ≤ 250 KB |
| `poster-art` | 3508 × 4961 (A1 art area at 150 dpi) portrait, or landscape for A0 | PNG master + JPG ≤ 800 KB at `target` | — |
| `animation` | 1280 × 720, 24 fps, **silent**, loopable, 8–30 s | MP4 (H.264) at `target` + a still `.jpg` with the same name beside it | ≤ 3 MB |
| `poster` | A1 594 × 841 mm (or A0 per `size`), 3 mm bleed | print PDF at `target` + phone JPG 1080 × 1528 at `phone_target` + editable source (SVG / Figma / .pptx) under `public/course-media/<course>/posters/src/` | JPG ≤ 400 KB |

The repo already has helpers: `scripts/animate-illustration.mjs`, `scripts/animate-lesson.mjs`,
`scripts/add-course-image.mjs` — reuse their encoding settings (see `lib/course-deck.ts` on why
clips never autoplay and must stay small: rural prepaid data).

## 4. Building a poster (kind = `poster`)

For each `poster` item, combine its `-ART` image with the typeset text from the manifest:

- `headline` → top band, Newsreader Bold (the app's display font), ≥ 120 pt
- `labels` → numbered callouts ①②③ placed on the art + a label row, Public Sans Bold 48–64 pt
- the question strip → Ochre italic (it is in the poster's **Layout** note in `posters.md`)
- top strip: poster ID + course + day, Forest background
- follow `poster-standards.md` §Layout grid; ≤ 25 words; must work in black & white
- **Back-of-poster card:** also export `teach_it` as an A5 PDF card:
  `public/course-media/<course>/posters/<ID>-card.pdf`

Keep all words in editable text layers — posters will be translated to isiZulu, Sesotho,
siSwati, Xitsonga, Sepedi, isiXhosa. Name translated exports `<ID>.zu.pdf`, `<ID>.st.pdf`, etc.

## 5. After you add files

```bash
python3 scripts/courses/build.py          # rebuilds decks: placeholders become your images
python3 scripts/courses/build.py --check  # must print 0 problems
```

The decks pick up any file that exists at `target` (or the clip's `.jpg` still for animations)
automatically. Commit the new media, the rebuilt `courses/build/**` and the manifest together.
