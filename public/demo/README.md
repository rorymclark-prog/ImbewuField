# Fictional demonstration images

Generated on 2026-09-05 with the built-in image-generation tool, in generation mode (no reference images). Images depict invented people and places. They are reused across sample profiles and must never be represented as participant evidence, actual sales, or a surveyed site. The demo aerial does not change the saved Design Studio geometry.

Delivery assets are WebP copies: portraits and produce at 512 px; the aerial at 1024 px. The app labels these as fictional sample material. Image generation was used only for these demo assets, not for reports, training evidence or real farm maps.
