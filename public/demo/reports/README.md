# Completed garden sample reports

Prepared 6 September 2026. One four-page PDF and matching schematic PNG per
catalogue garden, g1–g18. These are fictional examples, not verified reports.

Body content: `lib/sample-garden-reports.ts`, using `lib/sample-gardens.ts`.
Layout source: `sampleGardenSvg` in `lib/sample-garden-layout.ts`.
Photographs: the corresponding `public/demo/sites/gN.jpg` AI-generated reference.
Partner logos are illustrative shared demo branding.

The PDFs contain all eight shared report sections, a site photo and a schematic.
Regenerate these snapshots when catalogue figures or report narratives change;
keep URLs stable so gallery and dashboard links continue to work. Prepared PDFs
use embedded DejaVu fonts, compressed site photographs and ReportLab. The app's
Generate new report PDF action renders the same report sections with the selected
format and images. Neither route calls a live AI service for this sample.

These 18 catalogue reports do not replace the connected Ubhejane farm's separate
site-analysis report, nor do they establish 18 editable Design Studio workspaces.
