# Uluhlu lwamagama

Amanye amagama e-permaculture awanalo igama elifutshane lansuku zonke ezilimini zethu zasekhaya. Kuzo zonke izilimi zale ncwadi, la magama agcinwa **ngesiNgesi**, ukuze abalimi, abacebisi bezolimo, abaqeqeshi nabathengisi bonke basebenzise igama elifanayo. Isahluko ngasinye sichaza igama xa livela okokuqala. Olu luhlu lulichaza onke endaweni enye.

| Igama | Intsingiselo |
|---|---|
| Animal tractor | Izilwanyana ezinjengeenkukhu ezigcinwa kwisibaya esihambayo ebhedini yegadi. Ziyakrwela, zikhupha ukhula, zitya izinambuzane ezonakalisa izityalo kwaye zongeza ubulongwe, emva koko isibaya sihanjiswa siye kwibhedi elandelayo. Ikwabizwa ngokuba yi-*chicken tractor*. |
| Annual | Isityalo esikhula, sityatyambe, senze imbewu size sife kunyaka omnye okanye kwisizini enye, njengombona, iimbotyi okanye iletisi. |
| Appropriate technology | Izixhobo neendlela ezilula nezingabizi, abantu basekuhlaleni abanokuzakha, bazisebenzise, bazilungise ngokwabo, ezinjenge-rocket stove okanye i-solar dryer. |
| Berm | Udonga oluphantsi lomhlaba, oluqhele ukwakhiwa ngakwicala elisezantsi le-swale, olunceda ukubamba amanzi ethambekeni. |
| Biodiversity | Ukwahlukahlukana kwezinto eziphilayo kwindawo: izityalo, izilwanyana, izinambuzane, iintaka, ubomi bomhlaba nokungunda. Ukwahlukahlukana okukhulu kwenza ifama iqine. |
| Biogas digester | Itanki evaliweyo apho ubulongwe bezilwanyana nenkunkuma yokutya kubola khona ngaphandle komoya, kukhuphe i-biogas (ikakhulu yi-methane) yokupheka, kunye nesichumiso esingamanzi esibizwa ngokuba yi-slurry. |
| Biomass | Zonke izinto zezityalo nezilwanyana ezikhula emhlabeni wakho: amagqabi, iziqu, ingca enqunyiweyo, amasebe anqunyiweyo, ubulongwe. Zinokusetyenziswa njenge-mulch, njenge-compost, njenge-fodder okanye njengeenkuni. |
| Biosecurity | Amanyathelo owathathayo ukuthintela izifo nezinambuzane zingeni kwifama yakho okanye zisasazeke phakathi kwezilwanyana, njengokugcina izilwanyana ezintsha zahlukile ixesha elithile. |
| Blackwater | Amanzi asuka kwizindlu zangasese nakwiidayapha. Aphethe iintsholongwane kwaye ungawasebenzisi neze kwigadi yokutya. |
| Canopy | Ileko eliphezulu le-food forest: imithi emide kakhulu, amagqabi ayo enza uphahla phezu kwezityalo eziphantsi. |
| Carbon to nitrogen ratio | Ulungelelwaniso phakathi kwezinto "ezomileyo" (i-carbon, ezinjengamagqabi omileyo nengca eyomileyo) nezinto "eziluhlaza" (i-nitrogen, ezinjengengca entsha nobulongwe) kwinqwaba ye-compost. Iinxalenye ezingama-25 ukuya kwezingama-30 zezinto ezomileyo kwinxalenye e-1 yezinto eziluhlaza ziyasebenza kakuhle. |
| Catchment | Indawo yomhlaba okanye yophahla apho amanzi emvula ahamba khona aye kwindawo enye, enjengetanki, ichibi okanye umlambo. |
| Chop and drop | Ukunqumla izityalo uyeke into onqumle yona iwele emhlabeni njenge-mulch, apho ibola khona ize ondle umhlaba. |
| Climate change | Utshintsho lwexesha elide kwimozulu, olubangelwa ikakhulu yimisebenzi yabantu. EMzantsi weAfrika lukhokelela kwimini eshushu ngakumbi, imvula engathembekanga, iimbalela ezinde nezaqhwithi ezinamandla ngakumbi. |
| Companion planting | Ukutyala kunye izityalo ezincedisanayo, umzekelo ngokutsala izinambuzane eziluncedo, ukudida izinambuzane ezonakalisayo okanye ngokunika umthunzi. |
| Compost | Izinto zezityalo nezilwanyana ezibole zaba zizinto ezimnyama, ezithambileyo, ezinevumba elimnandi, ezondla umhlaba. |
| Contour | Umgca odlula ngaphesheya kwethambeka kodwa ohlala kumgangatho ofanayo ukusuka ekuqaleni ukuya ekupheleni. Ii-swale, iibhedi nokulima kufanele kulandele i-contour. |
| Coppicing | Ukunqunqa isihlahla usondele emhlabeni ukuze sihlume amahlumela amatsha, anokuphinda anqunyulwe kamva ukuze kufunyanwe iintsika, iinkuni okanye i-fodder. |
| Crop rotation | Ukuhambisa usapho ngalunye lwezityalo luye kwibhedi eyahlukileyo kwisizini nganye okanye ngonyaka ngamnye, ukuze izinambuzane nezifo zingaqokelelani, kwaye umhlaba uhlale ulinganile. |
| Double-reach bed | Ibhedi yegadi ephakanyisiweyo emxinwa ngokwaneleyo (malunga no-1 ukuya kwi-1.2 m ububanzi) ukuze ufikelele embindini usuka kumacala omabini, ungaze unyathele emhlabeni. |
| Drip irrigation | Ukunkcenkcesha ngeepayipi ezinemingxuma emincinci okanye izitshizi zamathonsi (drippers) ezikhupha amanzi ngokucothayo ezantsi kwesityalo ngasinye. Iyonga amanzi amaninzi. |
| Ecosystem | Liqela lezityalo, izilwanyana, ubomi bomhlaba nokungunda ezihlala kunye nomhlaba, amanzi nomoya ozijikelezileyo. |
| Edge | Indawo edibana ngayo iindawo ezimbini ezahlukeneyo, njengomphetho wechibi okanye wehlathi. Imiphetho ihlala ibe ziindawo ezityebileyo kakhulu ngobomi nokukhula. |
| Erosion | Ukukhukuliswa okanye ukuphephethwa komhlaba ngamanzi okanye ngumoya, ngakumbi emhlabeni ongenanto okanye odliwe kakhulu yimfuyo. |
| Firebreak | Umcu womhlaba ocociweyo okanye otshisiweyo ukuze umlilo wasendle ungakwazi ukuwuwela. Umthetho woMzantsi Afrika ufuna ii-firebreak kwimida emininzi yamafama. |
| First-flush diverter | Isixhobo esikwi-gutter okanye epayipini esilahla imvula yokuqala engcolileyo kakhulu evela ophahleni, ngaphambi kokuba amanzi acocekileyo ahambe aye etankini. |
| Fodder | Izityalo ezilinywayo okanye ezibuthwayo ukondla izilwanyana, ezinjengengca, i-lucerne, iimbotyi zemithi namagqabi emithi. |
| Food forest | Igadi etyalwe njengehlathi lendalo, ngamaleko emithi, izihlahla ezincinci, imifuno enevumba, izityalo ezigubungela umhlaba nezityalo ezikhwelayo, enika ukutya ngomsebenzi omncinci emva kokuba isele iqinile. |
| Frost pocket | Indawo esezantsi apho umoya obandayo uhlala khona ngobusuku obungenamoya nobucacileyo, ukuze iqabaka libe likhulu apho kunasethambekeni eliphezulu. |
| Grafting | Ukudibanisa isiqwenga sesinye isityalo (esinjengohlobo oluhle lwesiqhamo) kwiingcambu zesinye isityalo, ukuze zikhule zibe ngumthi omnye. |
| Green manure | Isityalo, rhoqo esesosapho lweembotyi (i-legume), esityalelwa ukuba sinqunyulwe okanye simbelwe emhlabeni ukuze sawondle, hayi ukuba sivunwe. |
| Greywater | Amanzi asetyenzisiweyo asuka ekuhlambeni, kwiibhafu nakwiibhesini (hayi asezindlwini zangasese). Ngokuyisebenzisa ngononophelo, ingakwazi ukunkcenkcesha imithi nezityalo ezingezizo ezokutya. |
| Groundcover | Izityalo eziphantsi ezisasazeka phezu komhlaba ziwukhusele, ezinjengamathanga, ibhatata okanye i-clover. |
| Guild | Iqela lezityalo (ngamanye amaxesha nezilwanyana) elibekwe kunye ngeenxa zonke kwesona sityalo siphambili, rhoqo umthi weziqhamo, ukuze zincedisane. |
| Habitat | Indawo yendalo yokuhlala yesityalo okanye yesilwanyana, enokutya, amanzi nendawo yokukhosela eziyifunayo. |
| Humus | Inxalenye emnyama, ezinzileyo ye-organic matter emhlabeni, eshiyekayo emva kokuba izinto zezityalo nezilwanyana sezibole kanye. Ibamba amanzi nezondlo. |
| Indigenous | Isityalo okanye isilwanyana somdabu, esikhula ngokwendalo kwindawo kwaye singazanga ngabantu. |
| Infiltration | Amanzi afunxwa phantsi emhlabeni endaweni yokuba aqukuqele phezu komhlaba. |
| Invasive species | Isityalo okanye isilwanyana esivela kwenye indawo, esisasazeka singalawulwa size sonakalise iindawo zendalo, ukufumaneka kwamanzi okanye ezolimo. EMzantsi Afrika, izityalo nezilwanyana ezingengobasekhaya ezihlaselayo ezibhalwe kuluhlu zilawulwa ngumthetho (i-NEMBA). |
| Keyhole bed | Ibhedi yegadi ejikelezileyo enendlela ekhutshwe kuyo njengomngxuma wesitshixo, ukuze ufikelele kwibhedi yonke ungayinyatheli. Rhoqo yakhiwa nebhasikithi ye-compost embindini. |
| Legume | Isityalo sosapho lweembotyi neeperezi. Uninzi lwee-legume luyakwazi ukuthatha inayitrojeni emoyeni luyongeze emhlabeni. |
| Microclimate | Imozulu yendawo encinci ejikeleze indawo ethile, enjengodonga olujonge emntla olufudumeleyo okanye indawo ephantsi epholileyo, enomthunzi. Ingahluka kakhulu kwimozulu yendawo yonke. |
| Mulch | Isigqubuthelo sengca eyomileyo, amagqabi okanye ezinye izinto esisasazwa emhlabeni ukuze uhlale ufumile, upholile nokhuselekile, nokuthintela ukhula. |
| Nitrogen fixer | Isityalo, rhoqo i-legume, esineengcambu ezisebenzisana neebhaktheriya ukuthatha inayitrojeni emoyeni ziyongeze emhlabeni. |
| Organic matter | Nantoni na emhlabeni ebikhe yaphila: iingcambu, amagqabi, ubulongwe, izinambuzane ezifileyo nobomi bomhlaba. |
| Perennial | Isityalo esiphila ngaphezu kweminyaka emibini, njengemithi yeziqhamo, i-rhubarb, imifuno enevumba neentlobo ezininzi zengca. |
| Permaculture | Indlela yokuyila iifama, amagadi noluntu ukuze zisebenze njengenkqubo yendalo zize ziqhubeke zivelisa izizukulwana nezizukulwana. Igama lidibanisa *permanent* (okuhlala kuhleli) ne-*agriculture* (ezolimo). |
| pH | Umlinganiselo wokuba umhlaba unamandla okubawa okanye umnandi kangakanani, kwisikali esisuka kwi-0 ukuya kwi-14. Uninzi lwezityalo lukhula kakuhle phakathi kwe-6 ne-7 malunga. |
| Pollinator | Isilwanyana, esinjengenyosi, ibhabhathane, ibhungane okanye intaka, esithwala umgubo wokuchumisa sisuka kwintyatyambo ukuya kwenye ukuze izityalo zenze iziqhamo nembewu. |
| Predator | Isilwanyana esidla ezinye izilwanyana. Egadini, ii-predator eziluncedo ezinjenge-ladybird, iintaka neentxoxo zitya izinambuzane ezonakalisayo. |
| Rocket stove | Isitovu esilula, esigcina ubushushu kakuhle, esitshisa iinkuni ezincinci zishushu kakhulu zicoceke, sisebenzisa iinkuni ezimbalwa kakhulu size senze umsi omncinci. |
| Rootstock | Inxalenye yengcambu yomthi odityanisiweyo, ekhethelwe ukomelela kwayo okanye ukuvumelana kwayo nomhlaba okanye nemozulu. |
| Runoff | Amanzi emvula aqukuqela phezu komhlaba endaweni yokuba afunxwe. |
| Sector | Amandla angena kumhlaba wakho evela ngaphandle, anjengelanga, umoya, umlilo, amanzi okanye ingxolo. Ucwangciso lwee-sector lubonisa kwimephu apho avela khona. |
| Slurry | Ulwelo olushiyekayo kwi-biogas digester. Lunokusetyenziswa njengesichumiso, kodwa hayi kwizityalo ezityiwa ziluhlaza. |
| Solar dryer | Ibhokisi okanye ikhabhinethi esebenzisa ubushushu belanga, ukutya kuthunzelwa elangeni elithe ngqo, ukuze iziqhamo, imifuno neenkozo ziomiswe ngokukhuselekileyo. |
| Succession | Utshintsho lwendalo, inyathelo ngenyathelo, kwezityalo nezilwanyana zendawo ngokuhamba kwexesha, umzekelo ukusuka emhlabeni ongenanto ukuya engceni, ukuya kwizihlahla. |
| Swale | Umsele olinganayo ombiwe ulandela i-contour yethambeka, ukuze ubambe amanzi emvula uwayeke angene emhlabeni. |
| Thermal mass | Izinto ezinzima ezinjengelitye, isitena okanye amanzi ezifunxa ubushushu emini zize ziwunike kancinci ebusuku. |
| Topsoil | Ungqimba ophezulu, omnyama kakhulu womhlaba, apho kufumaneka iingcambu ezininzi, ubomi bomhlaba ne-organic matter. |
| Trap crop | Isityalo esityalelwa ukutsala izinambuzane zisuke kwisityalo sakho esiphambili, ukuze zikhutshwe. |
| Understorey | Ileko lemithi emincinci nezihlahla ezikhula ngaphantsi kwe-canopy kwi-food forest. |
| Windbreak | Umqolo okanye ibhanti lemithi, izihlahla okanye ingca ende ecothisa umoya ikhusele izityalo, izilwanyana neekhaya. |
| Wonder bag | Isixhobo sokupheka esigcina ubushushu: ingxowa egcina ubushushu efakwa kuyo imbiza yokutya okubilayo ukuze kuqhubeke kuphekwa ngobushushu bako ngaphandle kokongeza iinkuni okanye amalahle. |
| Worm farm | Ibhokisi okanye isitya apho iintshulube ezikhethekileyo zomgquba (ii-red wiggler) ziguqula inkunkuma yasekhitshini ibe ngubulongwe beentshulube obutyebileyo ne-worm tea. |
| Worm tea | Ulwelo oluphuma kwi-worm farm. Xa luxutywe namanzi, lusisichumiso esingamanzi esithambileyo. |
| Zone | Ummandla wefama ohlelwe ngokokuba uyityelela kangakanani. I-Zone 0 yindlu, i-Zone 1 yigadi yasekhaya ekufutshane nekitshi, ukuya kwi-Zone 5, eshiywe injalo njengendalo. |

## Amanqaku aphambili

- Amagama akolu luhlu agcinwa ngesiNgesi kuzo zonke izilimi zale ncwadi.
- Isahluko ngasinye sichaza igama xa livela okokuqala; buyela apha nanini na xa ulibele elinye.
