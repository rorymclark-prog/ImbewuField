# Uhlu lwamagama

Amanye amagama e-permaculture awanalo igama elifushane lansuku zonke ezilimini zethu zasekhaya. Kuzo zonke izilimi zale ncwadi, lawa magama agcinwa **ngesiNgisi**, ukuze abalimi, abeluleki bezolimo, abaqeqeshi nabathengisi bonke basebenzise igama elifanayo. Isahluko ngasinye sichaza igama okokuqala uma livela. Lolu hlu luwachaza wonke endaweni eyodwa.

| Igama | Lichaza ukuthini |
|---|---|
| Animal tractor | Izilwane ezifana nezinkukhu ezigcinwa esibayeni esihambayo phezu kombhede wengadi. Ziyaphenya, zihlakula, zidla izinambuzane ezilimazayo futhi zengeza umquba, bese isibaya sihanjiswa siye embhedeni olandelayo. Ibizwa futhi ngokuthi *chicken tractor*. |
| Annual | Isitshalo esikhula, siqhakaze, senze imbewu bese sifa ngonyaka owodwa noma ngesizini eyodwa, njengommbila, ubhontshisi noma ulethisi. |
| Appropriate technology | Amathuluzi nezindlela ezilula, ezingabizi, abantu bendawo abangazakha, bazisebenzise futhi bazilungise ngokwabo, njenge-rocket stove noma i-solar dryer. |
| Berm | Udonga oluphansi lomhlabathi, oluvame ukwakhiwa ngasohlangothini oluya phansi lwe-swale, olusiza ukubamba amanzi emthambekeni. |
| Biodiversity | Ukwehlukahlukana kwezinto eziphilayo endaweni: izitshalo, izilwane, izinambuzane, izinyoni, izidalwa zomhlabathi nesikhunta. Ukwehlukahlukana okukhulu kwenza ipulazi liqine. |
| Biogas digester | Ithangi elivalekile lapho umquba wezilwane nezinsalela zokudla kubola khona ngaphandle komoya, kukhiphe i-biogas (ikakhulukazi i-methane) yokupheka, kanye nomanyolo owuketshezi obizwa ngokuthi yi-slurry. |
| Biomass | Zonke izinto zezitshalo nezilwane ezikhula emhlabeni wakho: amaqabunga, iziqu, utshani obugunyiwe, amagatsha athenwe, umquba wezilwane. Kungasetshenziswa njenge-mulch, i-compost, i-fodder noma izinkuni. |
| Biosecurity | Izinyathelo ozithathayo ukuvimba izifo nezinambuzane ukuba zingene epulazini lakho noma zisakazeke phakathi kwezilwane, njengokugcina izilwane ezintsha zihlukene nezinye isikhashana. |
| Blackwater | Amanzi aphuma ezindlini zangasese nasemanabukeni. Aphethe amagciwane futhi akumele neze asetshenziswe engadini yokudla. |
| Canopy | Ungqimba oluphezulu lwe-food forest: izihlahla ezinde kakhulu, amaqabunga azo enza uphahla phezu kwezitshalo ezingaphansi. |
| Carbon to nitrogen ratio | Ukulingana phakathi kwezinto "ezinsundu" (i-carbon, njengamaqabunga omile notshani obomile) nezinto "eziluhlaza" (i-nitrogen, njengotshani obusha nomquba wezilwane) enqwabeni ye-compost. Izingxenye ezingaba ngu-25 kuya ku-30 zezinsundu engxenyeni engu-1 yeziluhlaza zisebenza kahle. |
| Catchment | Indawo yomhlaba noma yophahla lapho amanzi emvula egelezela khona endaweni eyodwa, njengethangi, ichibi noma umfudlana. |
| Chop and drop | Ukusika izitshalo ushiye lokho okusikile phansi njenge-mulch, lapho kubola khona kondle umhlabathi. |
| Climate change | Ushintsho lwesikhathi eside lwezimo zezulu, olubangelwa ikakhulukazi yimisebenzi yabantu. ENingizimu ne-Afrika luletha izinsuku ezishisa kakhulu, imvula engathembeki, isomiso esithatha isikhathi eside neziphepho ezinamandla kakhulu. |
| Companion planting | Ukutshala ndawonye izitshalo ezisizanayo, isibonelo ngokuheha izinambuzane eziwusizo, ngokudida izinambuzane ezilimazayo noma ngokunikeza umthunzi. |
| Compost | Izinsalela zezitshalo nezilwane esezibolile zaba yinto emnyama, evuthulukayo, enephunga elimnandi, eyondla umhlabathi. |
| Contour | Umugqa onqamula umthambeka ohlala usezingeni elifanayo lokuphakama kuyo yonke indlela. Ama-swale, imibhede nokulima kufanele kulandele i-contour. |
| Coppicing | Ukusika isihlahla noma isihlahlana eduze nomhlabathi ukuze sihlume amahlumela amasha, angasikwa futhi kamuva abe yizigxobo, izinkuni noma i-fodder. |
| Crop rotation | Ukuhambisa umndeni ngamunye wezitshalo uye embhedeni ohlukile njalo ngesizini noma ngonyaka, ukuze izinambuzane ezilimazayo nezifo zingandi futhi umhlabathi uhlale ulinganisela. |
| Double-reach bed | Umbhede ophakanyisiwe omncane ngokwanele (cishe u-1 kuya ku-1.2 m ububanzi) ukuze ufinyelele maphakathi nawo usuka ezinhlangothini zombili, ungalokothi unyathele umhlabathi. |
| Drip irrigation | Ukunisela ngamapayipi anezimbotshana noma izinconsi ezikhipha amanzi kancane phansi kwesitshalo ngasinye. Konga amanzi amaningi. |
| Ecosystem | Umphakathi wezitshalo, izilwane, izidalwa zomhlabathi nesikhunta ezihlala ndawonye nomhlabathi, amanzi nomoya okuzungezile. |
| Edge | Indawo lapho izindawo ezimbili ezihlukene zihlangana khona, njengonqenqema lwechibi noma lwehlathi. Ama-edge avame ukuba yizindawo ezinothe kakhulu ngempilo nokukhula. |
| Erosion | Ukukhukhuleka noma ukupheshulwa komhlabathi ngamanzi noma ngumoya, ikakhulukazi emhlabathini ongenalutho noma odliwe ngokweqile yimfuyo. |
| Firebreak | Umzila womhlaba ohlanziwe noma oshisiwe ukuze umlilo wasendle ungakwazi ukuwuwela. Umthetho waseNingizimu Afrika udinga ama-firebreak emingceleni yamapulazi amaningi. |
| First-flush diverter | Ithuluzi elifakwa ku-gutter noma epayipini elilahla amanzi emvula okuqala, angcole kakhulu, avela ophahleni ngaphambi kokuba amanzi ahlanzekile angene ethangini. |
| Fodder | Izitshalo ezitshalwa noma eziqoqwa ukuze zondle izilwane, njengotshani, i-lucerne, amakhasi embewu namaqabunga ezihlahla. |
| Food forest | Ingadi etshalwe njengehlathi lemvelo, ngezingqimba zezihlahla, izihlahlana, amakhambi, ama-groundcover nezitshalo ezikhuphukayo, enikeza ukudla ngomsebenzi omncane uma isimile. |
| Frost pocket | Indawo ephansi lapho umoya obandayo uhlala khona ebusuku obuthulile nobucwebile, ngakho isithwathwa sibi kakhulu lapho kunasemthambekeni ongaphezulu. |
| Grafting | Ukuxhuma ucezu lwesitshalo esisodwa (njengohlobo oluhle lwesithelo) ezimpandeni zesinye isitshalo, ukuze zikhule ndawonye njengesihlahla esisodwa. |
| Green manure | Isitshalo, esivame ukuba yi-legume, esitshalwa ukuze sisikwe noma simbelwe emhlabathini ukuze siwondle, kunokuba sivunwe. |
| Greywater | Amanzi asetshenzisiwe okuwasha, okugeza emabhavini nasemasinki (hhayi awezindlu zangasese). Uma uqaphela, anganisela izihlahla nezitshalo ezingadliwa. |
| Groundcover | Izitshalo eziphansi ezisabalala phezu komhlabathi ziwuvikele, njengamathanga, ubhatata noma i-clover. |
| Guild | Iqembu lezitshalo (kwesinye isikhathi nezilwane) ezibekwe ndawonye zizungeze isitshalo esiyinhloko, esivame ukuba yisihlahla sezithelo, ukuze zisekelane. |
| Habitat | Ikhaya lemvelo lesitshalo noma lesilwane, elinokudla, amanzi nendawo yokukhosela esikudingayo. |
| Humus | Ingxenye emnyama, ezinzile ye-organic matter emhlabathini, esala ngemva kokuba izinto zezitshalo nezilwane sezibole ngokuphelele. Igcina amanzi nezakhamzimba. |
| Indigenous | Isitshalo noma isilwane esikhona ngokwemvelo endaweni futhi esingalethwanga ngabantu. |
| Infiltration | Ukungena kwamanzi phansi emhlabathini kunokuba ageleze phezu komhlaba. |
| Invasive species | Isitshalo noma isilwane esivela kwenye indawo esisakazeka singalawuleki futhi silimaze izindawo zemvelo, imithombo yamanzi noma ukulima. ENingizimu Afrika, izinhlobo ezihlaselayo ezisohlwini zilawulwa ngumthetho (NEMBA). |
| Keyhole bed | Umbhede wengadi oyindilinga onendlela esikwe kuwo njengembobo kakhiye, ukuze ufinyelele wonke umbhede ngaphandle kokuwunyathela. Uvame ukwakhiwa nobhasikidi we-compost maphakathi. |
| Legume | Isitshalo somndeni kabhontshisi nophizi. Ama-legume amaningi angathatha i-nitrogen emoyeni ayifake emhlabathini. |
| Microclimate | Isimo sezulu sendawo encane ezungeze indawo ethile, njengodonga olufudumele olubheke enyakatho noma umgodi opholile onomthunzi. Singahluka kakhulu kunesimo sendawo yonke. |
| Mulch | Isembozo sotshani obomile, amaqabunga, amabibi noma ezinye izinto ezisatshalaliswa phezu komhlabathi ukuze uhlale umanzi, upholile futhi uvikelekile, nokuvimba ukhula. |
| Nitrogen fixer | Isitshalo, esivame ukuba yi-legume, izimpande zaso zisebenzisana namagciwane ukuthatha i-nitrogen emoyeni ziyifake emhlabathini. |
| Organic matter | Noma yini emhlabathini eyake yaphila: izimpande, amaqabunga, umquba wezilwane, izinambuzane ezifile nezidalwa zomhlabathi. |
| Perennial | Isitshalo esiphila iminyaka engaphezu kwemibili, njengezihlahla zezithelo, i-rhubarb, amakhambi nezinhlobo eziningi zotshani. |
| Permaculture | Indlela yokuklama amapulazi, izingadi nemiphakathi ukuze isebenze njengezinhlelo zemvelo futhi iqhubeke ikhiqiza izizukulwane ngezizukulwane. Leli gama lihlanganisa amagama esiNgisi athi *permanent* (okuhlala njalo) no-*agriculture* (ezolimo). |
| pH | Isilinganiso sokuthi umhlabathi une-asidi noma une-alkali kangakanani, esikalini esisuka ku-0 kuya ku-14. Izitshalo eziningi zikhula kahle kakhulu phakathi kuka-6 no-7 cishe. |
| Pollinator | Isilwane, njengenyosi, uvemvane, ibhungane noma inyoni, esithutha impova isuka embalini iye kwenye ukuze izitshalo zenze izithelo nembewu. |
| Predator | Isilwane esidla ezinye izilwane. Engadini, ama-predator awusizo afana nama-ladybird, izinyoni namaxoxo adla izinambuzane ezilimazayo. |
| Rocket stove | Isitofu esilula, esivikelwe kahle ukushisa, esishisa izinkuni ezincane ngokushisa okukhulu nangokuhlanzekile, sisebenzisa izinkuni ezimbalwa kakhulu futhi senze intuthu encane. |
| Rootstock | Ingxenye yezimpande yesihlahla esixhunyelwe, ekhethwe ngenxa yamandla ayo noma ngokufanela kwayo umhlabathi noma isimo sezulu. |
| Runoff | Amanzi emvula ageleza phezu komhlaba kunokuba angene emhlabathini. |
| Sector | Amandla aqhamuka ngaphandle angena emhlabeni wakho, njengelanga, umoya, umlilo, amanzi noma umsindo. Ukuhlela ama-sector kubonisa ukuthi lawa mandla avelaphi. |
| Slurry | Uketshezi olusala ku-biogas digester. Lungasetshenziswa njengomanyolo, kodwa hhayi ezitshalweni ezidliwa zingaphekiwe. |
| Solar dryer | Ibhokisi noma ikhabethe elisebenzisa ukushisa kwelanga, linomthunzi ovimba ilanga eliqondile, ukomisa izithelo, imifino nokusanhlamvu ngokuphepha. |
| Succession | Ushintsho lwemvelo, olwenzeka kancane kancane, lwezitshalo nezilwane zendawo ngokuhamba kwesikhathi, isibonelo kusukela emhlabathini ongenalutho kuya otshanini kuya ezihlahlaneni. |
| Swale | Umsele osezingeni elilodwa ombiwe ulandela i-contour yomthambeka ukuze ubambe amanzi emvula futhi uwavumele angene emhlabathini. |
| Thermal mass | Izinto ezisindayo njengamatshe, izitini noma amanzi ezimunca ukushisa emini bese zikukhipha kancane ebusuku. |
| Topsoil | Ungqimba oluphezulu nolumnyama kakhulu lomhlabathi, lapho kutholakala khona iningi lezimpande, izidalwa zomhlabathi ne-organic matter. |
| Trap crop | Isitshalo esitshalwa ukuheha izinambuzane ezilimazayo zisuke esitshalweni sakho esiyinhloko, ukuze zisuswe. |
| Understorey | Ungqimba lwezihlahla ezincane nezihlahlana ezikhula ngaphansi kwe-canopy ku-food forest. |
| Windbreak | Umugqa noma ibhande lezihlahla, izihlahlana noma utshani obude olwehlisa amandla omoya futhi luvikele izitshalo, izilwane nemizi. |
| Wonder bag | Into yokupheka egcina ukushisa: isikhwama esivikelwe ukushisa okufakwa kuso ibhodwe lokudla okubilayo ukuze kuqhubeke kuvuthwa ngokushisa kwakho ngaphandle komlilo owengeziwe. |
| Worm farm | Isitsha lapho imisundu ekhethekile ye-compost (ama-red wiggler) iguqula izinsalela zasekhishini zibe yindle yemisundu enothile ne-worm tea. |
| Worm tea | Uketshezi oluchicima luphuma ku-worm farm. Uma luhlanjululwe ngamanzi, lungumanyolo owuketshezi othambile. |
| Zone | Ingxenye yepulazi ehlelwe ngokuthi kufanele uyivakashele kangaki. I-Zone 0 yindlu, i-Zone 1 yingadi yasekhishini, kuze kube yi-Zone 5, eshiywa injalo njengendle. |

## Amaphuzu amqoka

- Amagama akulolu hlu agcinwa ngesiNgisi kuzo zonke izilimi zale ncwadi.
- Isahluko ngasinye sichaza igama okokuqala uma livela; buyela lapha noma nini uma ukhohlwa elithile.
