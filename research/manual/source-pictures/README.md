# Original manual pictures

These 73 JPG files are byte-for-byte copies of the pictures in
`Permaculture-Manual-Images.zip`, under `1-Pictures-now-in-the-manual/`.
They are kept here so the supplied photographs and diagrams remain available
after the illustrated replacements were added.

The manual displays the current images from `public/manual/figures/`. These
source pictures are reference material and are not loaded by the app.
