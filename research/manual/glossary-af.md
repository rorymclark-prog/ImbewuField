# Afrikaans glossary — Permaculture Manual

> **Machine-drafted glossary for fluent-speaker review.** Every Afrikaans term here was drafted by
> a machine and has not yet been checked by a fluent Afrikaans speaker with farming knowledge. Do
> not treat it as final. Terms marked **(check)** are the least certain and should be reviewed first.

## How to use this glossary

- Use the Afrikaans term in this table every time the English term appears in an `af` chapter, so
  all chapters agree with each other and with the app (`lib/locales/af.ts`, `lib/locales/af-inline/`).
- Register: plain, everyday Standard Afrikaans, the way an extension officer (landbouvoorligter)
  would explain it on a farm. Use "jy/jou". Short sentences.
- Keep Latin plant names in italics, unchanged. Keep every plant, animal and species common name as
  the English writes it unless it is a plain everyday crop word (maize → mielies, beans → bone,
  pumpkin → pampoen, spinach → spinasie, cabbage → kool, carrots → geelwortels, sweet potato →
  patats). Never swap one species for another. Numbers and units stay exactly as in English.

## The 66 glossary words (Rory's keep-English decision, 26 Sep 2026)

The Glossary chapter (`12-glossary.md`) keeps the **Word** column exactly in English, as in every
language. In chapters 00–11 the decision exists so that no language uses an obscure coined word for a
technical term. Afrikaans already has established everyday words for nearly all of these
(kompos, erosie, kontoersloot), so the chapters use the Afrikaans word below and give the **English
glossary word in brackets the first time it appears in each chapter**, e.g. "kontoersloot (swale)",
so a reader can find it in the Glossary. Later uses in the same chapter: the Afrikaans word only.
Where the column says "English", the English word itself is used (it is the word Afrikaans farmers use).
**This applies the decision's intent rather than its letter; the content owner may prefer English.**
